# SEFI book manuscripts and source archive

Author: Jason D. Dutton.

This archive preserves the early illustrated textbook, subsequent book drafts, operator notes, and sample chapters. These are author manuscripts and proposals, not independently validated physical results. The illustrated textbook is the author's earliest work; the later SEFI, GWFM, and DEFI journal manuscripts are subsequent developments.

Identical copies are stored once. Private publisher correspondence, forms, credentials, and unrelated career records are excluded. Existing source files were not changed. Public repository storage does not establish journal acceptance or replace earlier submission history.
